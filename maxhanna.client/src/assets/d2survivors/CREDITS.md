## Locally supplied monster sheets

`monster-fallen.png`, `monster-zombie.png`, `monster-skeleton.png`, `monster-demon.png`, and `monster-lord.png` are converted animation sheets made from the DCC/COF files in the user's local `Data/Global/Monsters` directory. They are derived from user-provided Diablo II data and are not redistributable game assets.

`monster-palette-approx.dat` is a generated, 256-entry BGR palette used only because the supplied files did not include a base `pal.dat`. The colors are approximate and are not the original game palette. The sheets were assembled with the COF layer order; direction rows and frame columns are retained for runtime animation.
